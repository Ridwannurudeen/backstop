# AI Usage

AI tools were used during development for:

- Competitive research and positioning analysis.
- Frontend copy and layout iteration.
- SDK integration planning.
- README and submission package drafting.
- Code review assistance and validation planning.

Human-controlled work included:

- Product direction and final project selection.
- Mainnet deployment decisions.
- Any hackathon submission or external publication decision.
- Wallet signing and on-chain transaction approval.

No private keys, mnemonics, API secrets, or custody credentials are stored in
this repository.
